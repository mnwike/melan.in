Worth knowing

  • Silicones: Avoided in some curly-hair routines because of build-up, not because of safety.
  • Formaldehyde-releasing preservatives: Permitted within set limits; must carry a warning above a threshold.
  • Fragrance (parfum): If you have eczema or sensitive skin, fragrance-free is the safer choice.
  • Listed fragrance allergens: UK and EU rules require these to be listed by name above a set level.
